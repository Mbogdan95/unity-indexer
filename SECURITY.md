# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | ✓         |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Report via GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/Mbogdan95/unity-indexer/security/advisories/new)

You will receive a response within 48 hours. If the issue is confirmed, a patch will be released as soon as possible.
